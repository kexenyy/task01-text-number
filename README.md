# Task 01 - Text and Number 

## Description
This project contains simple Python functions for working with text and numbers.

## Features
- Counts the number of words in a sentence
- Finds the longest word in a sentence
- Reverses a sentence
- Checks whether a number is prime

## How to Run
1. Make sure Python is installed.
2. Open Command Prompt in the project folder.
3. Run the following command:

python task01.py

4. Enter a sentence and a number when asked.

## Example
Input:
Sentence: python is a language
Number: 5

Output:
Word count: 4
Longest word: language
Reversed sentence: egaugnal a si nohtyp
Prime check: Yes
